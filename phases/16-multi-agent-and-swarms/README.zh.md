# Phase 16: 多 Agent 系统与群体智能

> 协调、涌现与集体智能。

## 在 GitHub 上开始这一阶段

**Prerequisites:** 第 14 阶段（Agent Engineering）。首个 TypeScript demo 需要 Node.js 20+ 和
`npx`。

**第一课：** [为什么需要多 Agent](01-why-multi-agent/)

在仓库根目录运行这条命令：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

记住命令本身、退出码、单 agent 与多 agent 的 token 与 tool call
总数，以及一项让新增协调变得值得的权衡。

**下一步：** 更换任务，再次比较两种方案，然后
继续学习 [FIPA-ACL 传承与言语行为](02-fipa-acl-heritage/)。

浏览[完整的 Phase 16 课程列表](../../README.md#phase-16)或
[跨阶段路线图](../../ROADMAP.md)。
