给定一个需要从一群 agent 中涌现出行为的场景（社会模拟、游戏 NPC、政策演练、市场动态），设计这套模拟。

产出：

1. **种群规模与异构性。** N 个 agent；哪些共用基础模型、哪些不同；prompt 家族；角色分布。Smallville 用了 25 个同质 agent，但各自有个性化 persona；更大的种群受益于异构性。
2. **记忆 schema。** 每条记录的字段：`(ts, kind, content, importance, embedding_ref, source_ids)`。recency 衰减常数；importance 评分流程；relevance 度量（与 embedding 模型 X 的余弦）。压缩用的保留策略。
3. **反思节奏。** 触发条件：未处理重要性总和 > 阈值，或每 N 条观察，或按固定 tick。每次触发产生多少条反思。反思 prompt 模板。
4. **计划视野。** 日 / 小时 / 动作三个层级。哪些必选、哪些可选。修订触发：新观察的重要性 > 阈值且与当前计划矛盾。
5. **世界模型。** 空间网格、社会图、资源约束。什么算作一次观察（视线、对话、通知）。架构不会学到、必须显式编码的规范约束（容量上限、营业时间、私密空间）。
6. **种子目标。** 哪些 agent 被种下哪些优先级。可能相互竞争的重叠目标；应当并存的不冲突目标。
7. **预算。** 每个 agent 每 tick 的 LLM 调用数（观察 + 检索 + 反思 + 计划 + 行动）。每 agent 每 tick 的预期 token 数。T 个 tick 的模拟总成本。
8. **评估指标。** 可信度（人类评分者）、目标达成率、计数的协调事件、作为失效信号的空间规范违规。

硬性拒绝：

- 没有显式编码空间 / 社会规范的设计。架构会违反它们（Park 2023 的关门商店、单人卫生间失效）。
- 记忆可变的设计。记忆必须只追加；更正写成新记录。
- 每个 tick 都运行反思的设计。这会浪费预算；反思开销大，触发应当基于阈值。
- 大 N（> 50）却没有记忆压缩策略的模拟。检索成本随 stream 长度增长。

拒绝规则：

- 如果场景需要的是涌现式的*任务执行*，而非涌现式的*社会行为*，改为推荐 supervisor / 角色 / 原语模式（第 16 阶段 · 05-08）。Smallville 用于社会模拟。
- 如果预算只允许每 tick 总共不到 100 次 LLM 调用，推荐 N = 3-5 个 agent 并做密集交互，而不是更大的种群。
- 如果场景不会从涌现中受益（紧密脚本化的任务），推荐单 agent + 工具。

输出：一页纸设计简报。先用一句话概括（“Smallville 风格模拟：15 个异构 agent，在重要性总和 > 120 时反思，3 级计划视野，带容量约束的空间网格，以可信度 + 协调事件衡量。”），然后给出上面八节内容。结尾给出预期会出现的涌现行为，以及需要留意的头三个失效模式。
