# Phase 17: 基础设施与生产

> 把 AI 交付到真实世界。扩容、监控、优化。

## 在 GitHub 上开始这一阶段

**Prerequisites:** 第 11 阶段（LLM Engineering）与第 13 阶段（Tools and Protocols）。

**第一课：** [托管 LLM 平台](01-managed-llm-platforms/)

在仓库根目录运行这条命令：

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

记住命令本身、退出码、成本与延迟的对比、冗余带来的提升，
以及一份简短的决策记录，写下你的选择背后的工作负载假设。

**下一步：** 更换一个工作负载或 SLA 输入，解释新的选择，
然后继续学习 [推理平台经济学](02-inference-platform-economics/)。

浏览[完整的 Phase 17 课程列表](../../README.md#phase-17)或
