# Phase 10: 从零构建 LLM

> 构建、训练并理解大语言模型。

## 在 GitHub 上开始这一阶段

**Prerequisites:** Phase 5 NLP 基础。在进入模型构建课程前，强烈建议先完成 Phase 7 Transformers。

**第一课：** [分词器](01-tokenizers/)

在仓库根目录运行这条命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

记住命令本身、退出码、encode/decode 往返结果、学到的合并次数和压缩比。`tiktoken` 是可选的对照实现。

**下一步：** 往这个微型语料里加一个它没见过的新词，检查它被切成哪些片段，然后继续学习[从零构建分词器](02-building-a-tokenizer/)。

浏览[完整的 Phase 10 课程列表](../../README.md#phase-10)或[跨阶段路线图](../../ROADMAP.md)。
