# Phase 19: 毕业项目

> 证明你学到的一切。构建作品集级别的系统。

## 在 GitHub 上开始这一阶段

**Prerequisites:** 选择一个你已完成其列出的那些阶段的项目。
Terminal-Native Coding Agent 需要第 11、13、14、15 与 17 阶段。

**入门项目：** [终端原生编码 Agent](01-terminal-native-coding-agent/)

在仓库根目录运行这条命令：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

保留这条命令、退出码、最终计划状态、预算总计、trace 事件，以及
在接入真实模型之前你会改动的那个架构决策。

**下一步：** 从
[完整的第 19 阶段项目列表](../../README.md#phase-19) 中选择符合你目标的 capstone。项目是选择题，
而不是必须按数字顺序执行的序列。先写出验收证据，再开始构建。

使用 [跨阶段路线图](../../ROADMAP.md) 来补齐任何先修课的缺口。
