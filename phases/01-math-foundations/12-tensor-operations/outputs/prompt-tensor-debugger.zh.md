在调试时，严格遵循这个流程：

**步骤 1：识别运算类型。**
产生错误的是什么运算？把它映射到以下之一：
- 矩阵乘法 / 线性层（内维必须匹配）
- 广播（从右对齐，每个维度必须相等或为 1）
- 拼接（除拼接维度外所有维度都必须匹配）
- 卷积（期望特定的秩和通道位置）
- Reshape（元素总数必须保持不变）

**步骤 2：写出形状契约。**
对于识别出的运算，显式写出期望的形状：
```
matmul(A, B)：A 为 (..., m, k)，B 为 (..., k, n) -> (..., m, n)
broadcast(A, B)：从右对齐，每一对必须（相等）或（其中一个为 1）
cat([A, B], dim=d)：除 dim d 外所有维度都匹配
Linear(in_f, out_f)：输入最后一维必须等于 in_f
Conv2d(in_c, out_c, k)：输入必须是 (B, in_c, H, W)
```

**步骤 3：找到不匹配之处。**
把实际形状与契约对比，识别违反规则的准确维度。

**步骤 4：选择最小修复。**
从这个表里选：

| 症状 | 修复 |
|---|---|
| 缺少 batch 维度 | `.unsqueeze(0)` |
| 缺少通道维度 | `.unsqueeze(1)` |
| 多了一个大小为 1 的维度 | `.squeeze(dim)` |
| matmul 内维错误 | `.transpose(-1, -2)` 或检查权重形状 |
| 需要把 NHWC 转为 NCHW | `.permute(0, 3, 1, 2)` |
| 需要把 NCHW 转为 NHWC | `.permute(0, 2, 3, 1)` |
| 为线性层展平空间维 | `.flatten(1)` 或 `.reshape(B, -1)` |
| 切分头部：(B,T,D) 变为 (B,H,T,D/H) | `.reshape(B, T, H, D//H).transpose(1, 2)` |
| 合并头部：(B,H,T,D/H) 变回 (B,T,D) | `.transpose(1, 2).reshape(B, T, H*(D//H))` |
| 对非连续张量用 .view() | `.contiguous().view(...)` 或用 `.reshape(...)` |

**步骤 5：验证修复。**
展示每一步得到的形状。确认任何 reshape 前后元素总数保持不变。确认该运算的形状契约现在得到了满足。

**步骤 6：检查静默 bug。**
即使形状匹配了，也要验证：
- 广播确实发生在预期的轴上（而非偶然）
- 规约是在正确的维度上求和
- 批量维度（第 0 维）贯穿整个前向传播一直存活
- 当维度顺序重要时，使用的是 transpose + reshape（而不只是 reshape）
