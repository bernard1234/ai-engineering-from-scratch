# 凸性检查器

如何验证一个优化问题是否为凸，以及该如何处理这个答案。

## 决策清单

1. 目标函数是否为凸？（检查 Hessian 半正定，或使用复合规则。）
2. 所有不等式约束是否都形如 g_i(x) <= 0，且每个 g_i 都是凸的？
3. 所有等式约束是否都是仿射（线性）的？
4. 如果三者都是“是”，则问题是凸的。使用带收敛保证的凸求解器。
5. 如果任何一个为“否”，则问题是非凸的。使用 SGD/Adam 并接受局部最优。

## 如何检验一个函数的凸性

| 检验 | 适用于 | 方法 |
|---|---|---|
| 二阶导数 >= 0 | 标量函数 f(x) | 计算 f''(x)。如果对所有 x 都有 f''(x) >= 0，则凸。 |
| Hessian 半正定 | 多元函数 f(x) | 计算 H(x)。如果处处所有特征值 >= 0，则凸。 |
| 定义检验 | 任意函数 | 对采样的 x、y、t 检验 f(tx + (1-t)y) <= t*f(x) + (1-t)*f(y)。 |
| 复合规则 | 复合函数 | 见下方复合表。 |
| 限制到一条直线 | 多元 f | 对任意 x、v，f 凸当且仅当 g(t) = f(x + tv) 关于 t 是凸的。 |

## 复合规则（保持凸性）

| 运算 | 结果 |
|---|---|
| f + g（两者都凸） | 凸 |
| c * f（c > 0，f 凸） | 凸 |
| max(f, g)（两者都凸） | 凸 |
| f(Ax + b)，其中 f 凸 | 凸 |
| g(f(x))，其中 g 凸且非降、f 凸 | 凸 |
| g(f(x))，其中 g 凸且非增、f 凹 | 凸 |
| 凸函数之和 | 凸 |
| 凸函数的逐点上确界 | 凸 |

## 常见机器学习目标：凸还是非凸？

| 目标 | 凸？ | 原因 |
|---|---|---|
| MSE：(1/n) sum(y - Xw)^2 | 是 | 关于 w 二次，Hessian = (2/n) X^T X 半正定 |
| 逻辑损失：sum(log(1 + exp(-y_i * w^T x_i))) | 是 | 凸函数之和（log-sum-exp 族） |
| hinge 损失：sum(max(0, 1 - y_i * w^T x_i)) | 是 | 凸（线性）函数的最大值 |
| L2 正则化：lambda * \|\|w\|\|^2 | 是 | 二次，Hessian = 2*lambda*I |
| L1 正则化：lambda * \|\|w\|\|_1 | 是 | 绝对值之和（凸但不可微） |
| 岭回归：MSE + L2 | 是 | 两个凸函数之和 |
| LASSO：MSE + L1 | 是 | 两个凸函数之和 |
| Elastic net：MSE + L1 + L2 | 是 | 凸函数之和 |
| SVM（原始）：hinge + L2 | 是 | 凸函数之和 |
| 带 softmax 的交叉熵 | 是（关于 logits） | log-sum-exp 是凸的 |
| 神经网络（任意损失） | 否 | 非线性激活造成非凸复合 |
| k-means 目标 | 否 | 离散的分配步骤 |
| 矩阵分解：\|\|X - UV^T\|\|^2 | 否 | 关于 U 和 V 双线性 |
| GAN 损失 | 否 | 极小极大，关于生成器非凸 |
| 对比损失（InfoNCE） | 否 | 带负样本的指数比值的对数 |

## 基于凸性的求解器选择

| 问题类型 | 求解器 | 收敛保证 |
|---|---|---|
| 凸、光滑、无约束 | 梯度下降 | O(1/k) 到全局最小值 |
| 凸、光滑、无约束 | L-BFGS | 超线性到全局最小值 |
| 凸、光滑、无约束 | 牛顿法 | 在最小值附近二次收敛（若 Hessian 可处理） |
| 凸、光滑、有约束 | 内点法 | 多项式时间 |
| 凸、非光滑（L1） | 近端梯度 / ISTA | O(1/k) 到全局最小值 |
| 凸、非光滑（L1） | ADMM | 灵活，可处理约束 |
| 凸、二次 | 共轭梯度 | n 步内精确 |
| 非凸、光滑 | SGD / Adam | 收敛到局部最小值 |
| 非凸、光滑 | SGD + 重启 | 平均上更好的局部最小值 |
| 非凸、光滑 | 过参数化 + SGD | 平坦最小值，泛化好 |

## 常见错误

- 因为损失函数是凸的就假设问题是凸的。损失必须关于你正在优化的参数是凸的。交叉熵关于 logits 是凸的，但从输入到 logits 的完整神经网络映射是非凸的。
- 在非凸问题上使用牛顿法。Hessian 可能有负特征值，导致牛顿法走向鞍点或极大值而非极小值。
- 忘记 L1 正则化会让目标在零点不可微。标准梯度下降效果不好。应使用近端梯度下降或次梯度方法。
- 通过构造 A^T A 使条件数平方。如果你需要求解最小二乘问题且 A 病态，应使用 QR 或 SVD 而非正规方程。
- 未经检验就断言问题非凸。许多机器学习问题（线性模型、SVM、逻辑回归）是凸的，能从更强的求解器中受益。

## 快速检验：我的问题是不是凸的？

```
1. 写出目标：在约束下最小化 f(w)
2. 对 f(w) 中的每一项：
   - 它是带半正定矩阵的二次项吗？ -> 凸
   - 它是范数吗？ -> 凸
   - 它是 log-sum-exp 吗？ -> 凸
   - 它是否非线性地涉及 w（如 sigmoid(w)、w1*w2）？ -> 很可能非凸
3. 所有约束是否都是线性或凸的不等式？
4. 如果所有项都凸且约束凸/线性 -> 问题是凸的
5. 如果任一项非凸 -> 问题是非凸的
```
