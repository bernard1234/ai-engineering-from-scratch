# Phase 1：数学基础

> 每个 AI 算法背后的直觉，通过代码而非教科书来理解。

## 在 GitHub 上开始本阶段

**先决条件：** 完成 Phase 0，或确认 Python 3.11+ 和 Git 能在仓库根目录正常工作。

**第一课：** [Linear Algebra Intuition](01-linear-algebra-intuition/)

在仓库根目录运行此命令：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

保留命令、退出码、归一化向量的输出、投影残差，以及一句解释「为什么矩阵-向量乘积就是一个神经网络层」的话。

**下一步：** 改变一个输入向量，预测结果，再次运行，然后继续学习 [Vectors, Matrices and Operations](02-vectors-matrices-operations/)。

浏览 [完整的 Phase 1 课程列表](../../README.md#phase-1) 或 [跨阶段路线图](../../ROADMAP.md)。
