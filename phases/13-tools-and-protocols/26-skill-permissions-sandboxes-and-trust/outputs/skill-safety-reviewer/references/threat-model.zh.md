# 威胁模型

请独立审查以下这些边界：

- 权威（Authority）：指令不能改写宿主的权限。
- 文件系统：解析目标并让它留在工作区根目录内；拒绝符号链接逃逸。
- 命令：接受 argv 数组，拒绝 shell 元字符和破坏性可执行文件，并要求一份可执行文件 allowlist。
- 网络：要求 HTTPS 以及一份精确的源站 allowlist。规范化有效端口，使 `https://api.example.test` 与 `https://api.example.test:443` 匹配，而端口 `8443` 需要单独一条条目。不要接受 URL userinfo 中的凭证。
- 外部内容：把检索到的文本当作数据，绝不当成策略或审批。
- 密钥：检测可能携带密钥的载荷，且不记录它们的值。
- 破坏性动作：根据宿主策略拒绝，或要求一次有记录的人类审批。

`allow` 裁定只表示模拟的请求满足所提供的策略。这个 bundle 不执行任何动作。
