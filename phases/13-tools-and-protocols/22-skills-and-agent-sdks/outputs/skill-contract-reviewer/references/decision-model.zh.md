# Primitive 决策模型

按职责选择。可能不止一个 primitive 是正确的。

| 需求 | Primitive | 边界 |
|---|---|---|
| 一次性指令 | Prompt | 只存在于当前这次交互 |
| 仓库级默认规则 | AGENTS.md | 在该仓库作用域内工作时适用 |
| 可复用的任务方法 | Agent Skill | 为某个任务加载过程性知识 |
| 外部操作或数据 | MCP tool | 暴露带输入契约的可调用能力 |
| 对运行时事件的反应 | Hook | 在 host 定义的生命周期节点运行 |
| 确定性转换 | 普通代码 | 在无模型判断的情况下产出可重复结果 |
| 隔离或并行的上下文 | Subagent | 把有界任务委派到独立的上下文窗口 |

一个需要查询远程服务的发布审查方法，可能同时使用 Agent Skill 和 MCP tool。仓库的测试约定可以增加 AGENTS.md。post-tool 审计可以增加一个 hook。稳定的解析应放在普通代码里。能从上下文隔离中受益的独立调研可以使用 subagent。
