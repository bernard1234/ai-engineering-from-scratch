# 可移植契约清单

- bundle 是一个目录，其中包含一个普通的 `SKILL.md` 文件。
- Frontmatter 从第一行开始，并且有闭合分隔符。
- `name` 存在，不超过 64 个字符，且仅使用小写字母、数字和单个连字符。
- `name` 与 bundle 目录一致。
- `description` 存在，不超过 1024 个字符，并说明该 skill 何时有用。
- 可选的 `compatibility` 在存在时包含 1 到 500 个字符。
- 可选的 `metadata` 把字符串键映射到字符串值。
- 可选的实验性 `allowed-tools` 是一个非空的空格分隔字符串，其行为需在目标 host 中验证。
- 未知的运行时字段与可移植包契约分离，并由显式的 adapter 处理。
- Markdown 正文包含流程说明。
- 可移植的可选元数据与 host 特有的扩展保持可区分。

通过这份清单只意味着包在结构上可加载。它不授予文件系统、网络、密钥、子进程或 tool 权限。
