# Phase 12: 多模态 AI

> 能看、能听、能读，并能跨模态推理的模型。

## 在 GitHub 上开始这一阶段

**Prerequisites:** Phase 7 Transformers 与 Phase 4 计算机视觉。

**第一课：** [视觉 Transformer 与 Patch Token](01-vision-transformer-patch-tokens/)

在仓库根目录运行这条命令：

```bash
python3 phases/12-multimodal-ai/01-vision-transformer-patch-tokens/code/main.py
```

记住命令本身、退出码、patch 网格与序列长度、参数数量，以及一句解释为什么更高分辨率会产生更多视觉 token。

**下一步：** 改动一张图片或 patch 尺寸，先预测序列长度，然后继续学习 [CLIP 与对比预训练](02-clip-contrastive-pretraining/)。

浏览[完整的 Phase 12 课程列表](../../README.md#phase-12)或[跨阶段路线图](../../ROADMAP.md)。
