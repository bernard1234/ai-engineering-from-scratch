# Phase 15: 自主系统

> 无需人类干预即可安全运行的 agent。

## 在 GitHub 上开始这一阶段

**Prerequisites:** 第 14 阶段，第 01 课（The Agent Loop）。

**第一课：** [长时程 Agent](01-long-horizon-agents/)

在仓库根目录运行这条命令：

```bash
python3 phases/15-autonomous-systems/01-long-horizon-agents/code/main.py
```

记住命令本身、退出码、horizon 推算、复合可靠性表，
以及你在长时间运行之前会要求的一项运维控制。

**下一步：** 用不同的单步可靠性重新计算一条轨迹，
然后继续学习 [自学推理](02-star-family-reasoning/)。
