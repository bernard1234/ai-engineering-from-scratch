# 回归策略指南

回归预测连续值。合适的方法取决于特征和目标的关系、特征数量，以及过拟合的风险。

## 决策检查清单

1. 特征和目标之间的关系近似线性吗？
   - 是：从普通线性回归开始
   - 否：尝试多项式特征或非线性模型

2. 相对样本量来说，你有多少特征？
   - 特征少、样本多：普通线性回归就能工作
   - 特征多、样本少：使用正则化（Ridge 或 Lasso）
   - 特征比样本还多：用 Lasso（L1）做特征选择，或用 Ridge（L2）缩小所有权重

3. 你需要可解释性吗？
   - 是：少特征的线性回归，或 Lasso 做自动特征选择
   - 否：多项式特征，或转向树模型或神经网络

4. 你的数据集小吗（不足 10,000 行）？
   - 用正规方程（闭式解）以获得速度
   - 交叉验证对可靠评估至关重要

5. 你的数据集大吗（几百万行）？
   - 用随机梯度下降（SGD）或小批量梯度下降
   - 正规方程由于 O(n³) 的矩阵求逆太慢了

## 什么时候用每种方法

**普通线性回归**：任何回归任务的基线。从这里开始。如果 R-squared 可以接受且模型简单，就停在这里。

**多项式回归**：散点图显示曲线而非直线时。从 2 次开始。只有当验证性能有理由时才增加次数。次数 > 5 几乎总会过拟合。

**Ridge 回归 (L2)**：很多特征互相相关。所有权重都向零缩小但不会变成恰好零。当你相信所有特征都有贡献时用。

**Lasso 回归 (L1)**：很多特征，且你怀疑只有少数几个有用。Lasso 把无关特征的权重驱动到恰好零，完成自动特征选择。

**Elastic Net**：结合 L1 和 L2 惩罚。当你有很多相关特征又想做一些特征选择时用。

## 常见错误

- 梯度下降前跳过特征缩放（收敛变得极慢）
- 用测试集表现调超参数（应该用验证集或交叉验证）
- 拟合高次多项式却不检查验证误差（训练 R² 总会随次数增加而上升）
- 忽略残差图（如果残差显示出规律，R² 会有误导性）
- 把 R² 当作唯一指标（还要检查残差分布、MAE 和领域特定阈值）

## 快速参考

| 方法 | 何时用 | 正则化 | 特征选择 |
|------|--------|--------|----------|
| OLS | 基线，少特征 | 无 | 手动 |
| Ridge | 多特征，全部相关 | L2（缩小） | 无 |
| Lasso | 多特征，少数相关 | L1（置零） | 自动 |
| Elastic Net | 多相关特征 | L1 + L2 | 部分 |
| Polynomial | 非线性关系 | 在上面加 Ridge/Lasso | 手动选次数 |
