# 调参策略 Prompt

给定模型和数据集，推荐一个从粗到细的超参数调优流程。

## 调参流程

1. **建立基线**：默认参数下的交叉验证得分
2. **粗网格搜索**：每个参数 3–5 个点，覆盖大范围（对数尺度）
3. **识别好区域**：锁定性能好的参数组合周围的窄范围
4. **精细搜索**：在好区域做 20–50 次迭代（贝叶斯或小网格）
5. **验证**：用独立的验证集检查结果
6. **早停**：如果验证表现连续 N 轮不提升就停止

## 常见模型参数建议

| 模型 | 关键参数 | 搜索范围 |
|------|----------|----------|
| Logistic Regression | C | [0.001, 0.01, 0.1, 1, 10, 100] |
| Random Forest | n_estimators, max_depth | [50, 100, 200, 500] / [5, 10, None] |
| XGBoost | learning_rate, max_depth, n_estimators | [0.01, 0.05, 0.1] / [3, 5, 7] / 早停 |
| SVM | C, gamma | [0.001–1000] / [0.001–10]（都用对数尺度） |
| KNN | n_neighbors, metric | [3, 5, 7, 9] / euclidean, cosine |

## 注意事项

- 一定要用分层交叉验证（分类）或时间序列切分（时序）
- 报告 mean ± std，不要只报最高分
- 调完参数后，用 train + val 合并的数据重训最终模型
