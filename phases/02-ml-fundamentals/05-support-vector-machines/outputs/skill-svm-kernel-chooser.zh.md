# SVM 核函数选择指南

SVM 由两个选择定义：核函数（决定决策边界的形状）和正则化参数（控制边距宽度和分类错误之间的权衡）。把这些选对是从无用模型到强模型的关键。

## 决策检查清单

1. 数据线性可分吗（或接近线性可分）？
   - 是：用线性核。更快、更可解释。
   - 否：到第 2 步。

2. 特征数 vs 样本数？
   - 特征 >> 样本（比如 TF-IDF 文本）：用线性核。高维数据通常线性可分。RBF 加复杂度却没有增益。
   - 样本 >> 特征（比如 10–50 个特征的表格数据）：RBF 核是默认选择。

3. 决策边界预计是平滑的吗？
   - 平滑、连续的边界：RBF 核
   - 多项式形状的边界：多项式核（从 2 次或 3 次开始）
   - 领域知识暗示特定的交互项：匹配次数的多项式核

4. 数据集有多大？
   - 不到 10,000 样本：任何核都可以，RBF 是安全的默认
   - 10,000 到 100,000：线性核或 LinearSVC（原问题形式，每轮 O(n)）
   - 超过 100,000：不要用核 SVM。换成线性 SVM、梯度提升或神经网络。

5. 你缩放特征了吗？
   - SVM 需要特征缩放。拟合前一定要标准化（零均值、单位方差）。未缩放的特征会扭曲边距几何。

## 核函数选择流程

```
Start
  |
  v
特征 > 1000 或特征 >> 样本？
  Yes --> Linear kernel (LinearSVC for speed)
  No  --> Dataset < 10k samples?
            Yes --> Try RBF first (best general-purpose kernel)
            No  --> Linear kernel (kernel SVMs are O(n^2) to O(n^3))
```

如果 RBF 效果不好，试试 2–3 次多项式。如果还不行，问题可能不适合 SVM。

## 调 C（正则化）

C 控制对误分类的惩罚。它和正则化强度成反比。

| C 值 | 效果 | 何时用 |
|------|------|--------|
| 0.001 – 0.01 | 宽边距，允许很多违规 | 噪声数据，想要泛化 |
| 0.1 – 1.0 | 平衡 | 好的起点范围 |
| 10 – 1000 | 窄边距，很少违规 | 干净数据，需要高准确率 |

调参策略：
- 从 C=1.0 开始
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 用交叉验证选最佳值
- 如果最佳 C 正好在你范围的边界上，朝那个方向扩展范围

## 调 gamma（RBF 核）

Gamma 控制单个训练点的影响范围。它定义高斯核的宽度。

| gamma 值 | 效果 | 何时用 |
|----------|------|--------|
| 小（0.001） | 每个点影响很大区域。平滑、简单的边界 | 欠拟合或特征少 |
| 中（auto: 1/n_features） | sklearn 默认。合理起点 | 通用 |
| 大（10+） | 每个点只影响附近点。复杂、蜿蜒的边界 | 过拟合风险 |

调参策略：
- 从 gamma="scale"（1 / (n_features * X.var())，sklearn 默认）开始
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10]
- 低 gamma + 高 C 倾向过拟合
- 高 gamma + 低 C 倾向欠拟合

## 联合调 C 和 gamma

C 和 gamma 会相互作用。一定要一起调，不要独立地调。

推荐方式：
1. 粗略网格搜索：C ∈ [0.01, 0.1, 1, 10, 100]，gamma ∈ [0.001, 0.01, 0.1, 1, 10]（25 个组合）
2. 找到最佳区域
3. 在最佳区域附近做精细网格搜索（比如 C ∈ [5, 10, 20, 50]，gamma ∈ [0.05, 0.1, 0.2]）
4. 全程用 5 折交叉验证

## 常见错误

- 在高维稀疏数据上用 RBF 核（线性更好且快 100 倍）
- 忘了缩放特征（SVM 最常见的单一错误）
- 在噪声数据上 C 设太高（记住噪声而不是学边界）
- 在超过 50k 样本的数据集上用核 SVM（训练时间不堪重负）
- C 和 gamma 分开调（它们互相补偿）
- 默认用 5+ 次多项式（过拟合极严重，先试 2 或 3 次）

## 快速参考

| 核函数 | 何时用 | 关键参数 | 训练复杂度 |
|--------|--------|----------|------------|
| Linear | 文本/TF-IDF、多特征、大数据 | 只有 C | 每轮 O(n) |
| RBF | 通用、10k 样本以内 | C, gamma | O(n²) 到 O(n³) |
| Polynomial | 已知多项式关系 | C, degree, coef0 | O(n²) 到 O(n³) |
| Sigmoid | 很少有用（等价于两层神经网络） | C, gamma, coef0 | O(n²) 到 O(n³) |
