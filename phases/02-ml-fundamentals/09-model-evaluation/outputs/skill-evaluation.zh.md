# 模型评估策略

正确评估任何 ML 模型的检查清单。按这个顺序走，避开最常见的评估错误。

## 第 1 步：正确切分数据

- 在任何预处理（缩放、填充、编码）之前先切分
- 分类任务用分层切分
- 留出一个测试集，你只在最后碰它一次
- 小数据集用 5 折或 10 折交叉验证代替单次切分
- 时间序列用基于时间的切分（绝不要打乱）

## 第 2 步：选对指标

### 分类

| 情况 | 用这个指标 | 为什么 |
|------|------------|--------|
| 类别平衡、简单对比 | Accuracy | 容易解释，类别相等时有意义 |
| 假阳性代价高（垃圾邮件、欺诈警报） | Precision | 衡量标记的条目里真正为正的比例 |
| 假阴性代价高（癌症筛查、安全） | Recall | 衡量你抓到了多少实际正样本 |
| 要平衡精确率和召回率 | F1 Score | 调和平均，惩罚极端不平衡 |
| 跨阈值比较模型 | AUC-ROC | 阈值无关的排名质量 |
| 不平衡数据 | F1、AUC-ROC 或 PR-AUC | 不平衡下 Accuracy 有误导性 |

### 回归

| 情况 | 用这个指标 | 为什么 |
|------|------------|--------|
| 标准回归、可接受异常值 | RMSE | 和目标同单位，惩罚大错误 |
| 对异常值鲁棒的评估 | MAE | 平等对待所有错误，不被异常值主导 |
| 不同尺度上的模型对比 | R-squared | 归一化 0-1 尺度（解释的方差比例） |
| 业务需要金额数字 | MAE 或 RMSE | 直接解释为错误幅度 |

## 第 3 步：建立基线

在评估你的模型之前，先算基线表现：
- 分类：多数类预测器（永远预测最常见的类）
- 回归：永远预测训练目标的均值
- 任何模型赢不了这些基线就不算在学习

## 第 4 步：交叉验证

- 用 K 折（K=5 或 K=10）获得稳定估计
- 分类用分层 K 折
- 报告跨折的均值和标准差
- mean=0.85, std=0.02 的模型比 mean=0.87, std=0.10 的更可信

## 第 5 步：统计上比较模型

- 不要不检查显著性就选平均分数最高的模型
- 跨交叉验证折做配对 t 检验
- 如果 |t| < 2.78（K=5, df=4, p<0.05），差异可能是偶然的
- 性能差异不显著时，选更简单的模型

## 第 6 步：检查常见错误

- 数据泄露：有任何测试数据信息流进训练了吗？（切分前缩放、从目标派生特征）
- 类别不平衡：Accuracy 是不是在掩盖少数类的糟糕表现？
- 过拟合：训练和验证表现的差距大吗？
- 太多次评估：你看测试集超过一次了吗？

## 第 7 步：报告最终性能

- 在训练 + 验证的合并数据上训练
- 在留出的测试集上恰好评估一次
- 如果可能，带置信区间报告选好的指标
- 陈述基线对比（比随机/均值好多少）
