# 模型评估

> 一个模型的好坏取决于你怎么衡量它。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 1 (概率与分布、ML 统计), Phase 2 Lessons 1-8
**Time:** ~90 minutes

## Learning Objectives

- 从零实现 K 折和分层 K 折交叉验证，并解释为什么分层对不平衡数据重要
- 从零计算 precision、recall、F1、AUC-ROC 和回归指标（MSE、RMSE、MAE、R²）
- 解读学习曲线，诊断模型是高偏差还是高方差
- 识别常见评估错误，包括数据泄露、选错指标和测试集污染

## 问题场景

你训练了一个模型。它在你的数据上拿到了 95% 准确率。它好吗？

也许。也许不是。如果你的数据 95% 属于一个类别，一个永远预测那个类的模型也能拿到 95% 准确率，但它完全没用。如果你在训练过的同一批数据上评估，95% 这个数字没有任何意义——模型只是记住了答案。如果你的数据集有时间维度，你在切分之前随机打乱了，那模型可能用了未来数据来预测过去。

模型评估是大多数 ML 项目翻车的地方。用错指标让坏模型看起来好。用错切分让模型作弊。比较方法不对会让你选到更差的模型。评估做对不是可选项——它是"生产上能跑的模型"和"一见真实数据就崩的模型"之间的分界线。

## 核心概念

### 训练集、验证集、测试集

（mermaid 图保留）

三次切分，三种用途：

- **训练集**：模型从这些数据中学习。它在训练期间看到这些样本。
- **验证集**：用来调超参数和在模型之间选择。模型永远不会在这个数据上训练，但你的决策受它影响。
- **测试集**：只在最后摸一次，用来报告最终性能。如果你看了测试性能然后回去改模型，它就不再是测试集了——它变成了第二个验证集。

测试集是你的"留出保证"——确保报告的性能确实反映了模型在真正未见数据上的表现。

### K 折交叉验证

数据集小的时候，单次 train/validation 切分会浪费数据，而且估计有噪声。K 折交叉验证把所有数据都用于训练和验证：

（mermaid 图保留）

1. 把数据分成 K 个大小相等的折
2. 对每个折，在另外 K-1 折上训练，在剩余这一折上验证
3. 对 K 次验证分数取平均

K=5 或 K=10 是标准选择。每个数据点恰好用一次做验证。平均分比任何单次切分都更稳定。

**分层 K 折**：保持每个折里的类别分布。如果你的数据集 70% 是 A 类、30% 是 B 类，每个折里也大致是这个比例。对不平衡数据集尤其重要——随机切分可能把所有少数类样本塞进一个折里。

### 分类指标

**混淆矩阵**：基础。二分类情况：

|  | 预测正 | 预测负 |
|--|---|---|
| 实际正 | 真阳性 (TP) | 假阴性 (FN) |
| 实际负 | 假阳性 (FP) | 真阴性 (TN) |

从这个矩阵出发，所有其他指标自然得出：

- **Accuracy** = (TP + TN) / (TP + TN + FP + FN)。正确预测的比例。类别不平衡时有误导性。
- **Precision** = TP / (TP + FP)。所有预测为正的里面，有多少真的是正的？当假阳性代价高时用（比如垃圾邮件过滤器把真邮件标成垃圾）。
- **Recall（敏感度）** = TP / (TP + FN)。所有实际为正的里面，我们抓到了多少？当假阴性代价高时用（比如癌症筛查漏掉了肿瘤）。
- **F1 分数** = 2 × precision × recall / (precision + recall)。precision 和 recall 的调和平均。两者没有明显谁更重要时用来平衡。
- **AUC-ROC**：接收者操作特征曲线下面积。画出不同分类阈值下的真阳性率 vs 假阳性率。AUC = 0.5 意味着随机猜测，AUC = 1.0 意味着完美分离。阈值无关：它衡量模型把正样本排到负样本上面的能力，不管你选哪个 cutoff。

### 回归指标

- **MSE**（均方误差）= mean((y_true - y_pred)²)。大误差被平方惩罚。对异常值敏感。
- **RMSE**（均方根误差）= sqrt(MSE)。和目标变量同单位，比 MSE 好解释。
- **MAE**（平均绝对误差）= mean(|y_true - y_pred|)。对所有误差线性处理，比对 MSE 更能扛异常值。
- **R²** = 1 - SS_res / SS_tot，其中 SS_res = Σ(y_true - y_pred)²，SS_tot = Σ(y_true - y_mean)²。模型解释的方差比例。R² = 1.0 完美。R² = 0.0 意味着模型不比永远预测均值好。如果模型比均值还差，R² 可以是负的。

### 学习曲线

把训练分数和验证分数画成训练集大小的函数：

- **高偏差（欠拟合）**：两条曲线都收敛到一个低分。加更多数据没用。你需要更复杂的模型。
- **高方差（过拟合）**：训练分数高但验证分数低得多。两者差距很大。加更多数据应该有帮助。

### 验证曲线

把训练分数和验证分数画成一个超参数的函数：

- 复杂度低时：两条分数都低（欠拟合）
- 复杂度合适时：两条分数都高且彼此接近
- 复杂度高时：训练分数持续高但验证分数下降（过拟合）

最优超参数值就是验证分数达到峰值的地方。

### 常见评估错误

**数据泄露**：测试集的信息泄露进训练。例子：切分之前在整个数据集上拟合 scaler，时间序列预测时引入未来数据，用从目标变量派生的特征。永远先切分再做预处理。

**类别不平衡**：99% 的交易是合法的，1% 是欺诈。永远预测"合法"的模型能拿到 99% 准确率。改用 precision、recall、F1 或 AUC-ROC。

**选错指标**：你应该优化 recall（医疗诊断）的时候在优化 accuracy，或者数据有重尾异常值的时候在优化 RMSE（改用 MAE）。

**没用分层切分**：不平衡数据上，随机切分可能在验证折里放很少的少数类样本，给出不稳定的估计。

**测试太频繁**：每次你看了测试性能然后回去调，你就对测试集过拟合了。测试集是一次性的。

## Key Terms

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| Overfitting | "记住了训练数据" | 模型捕获了训练数据里的噪声，训练上好但未见数据上差 |
| Cross-validation | "在不同子集上测试" | 系统地轮换哪部分数据用来做验证，取所有轮换的平均 |
| Precision | "预测为正的里面有多少对了" | TP / (TP + FP)：正预测里实际为正的比例 |
| Recall | "实际为正的我们找到了多少" | TP / (TP + FN)：实际正样本里被正确识别的比例 |
| AUC-ROC | "模型分离类别的能力有多好" | 所有阈值下真阳性率 vs 假阳性率曲线下面积，0.5（随机）到 1.0（完美） |
| R² | "解释了多少方差" | 1 - 残差平方和 / 总平方和：目标方差被模型捕获的比例 |
| Data leakage | "模型作弊了" | 训练时用了预测时不会有的信息，导致评估结果虚高 |
| Learning curve | "性能随更多数据怎么变" | 训练和验证分数 vs 训练集大小的曲线，揭示欠拟合或过拟合 |
| Stratified split | "保持类别比例平衡" | 切分数据让每个子集里每类的比例和完整数据集一样 |
