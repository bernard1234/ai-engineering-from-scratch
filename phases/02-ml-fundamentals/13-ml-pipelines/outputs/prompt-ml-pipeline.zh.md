# ML 流水线设计 Prompt

给定一个业务问题，设计从原始数据到生产部署的完整流水线。

## 流水线阶段

1. **数据获取**：数据源（文件/数据库/API）、更新频率、数据量
2. **数据验证**：检查 schema、缺失率、唯一值、异常分布
3. **预处理**：
   - 缺失值策略（填充/删除/标记）
   - 数值变换（缩放/log/分箱）
   - 类别编码（one-hot/target/hash）
   - 特征选择（方差阈值/互信息/正则化）
4. **模型训练**：
   - 基线模型
   - 3–5 个候选模型
   - 交叉验证方案
   - 超参数调优策略
5. **评估**：
   - 主指标 + 业务指标
   - 混淆矩阵 / 残差图 / 学习曲线
   - 与基线对比
6. **模型选择**：性能 + 可解释性 + 训练/推理成本
7. **部署**：模型版本管理、推理服务、监控告警
8. **监控**：数据漂移（PSI）、性能退化、业务指标

## 输出格式

对每个阶段，列出关键组件、工具选择和验证方式。标出数据泄露风险点。
