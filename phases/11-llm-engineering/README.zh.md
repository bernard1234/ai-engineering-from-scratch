# Phase 11: LLM 工程

> 把 LLM 真正用进生产应用。

## 在 GitHub 上开始这一阶段

**Prerequisites:** Phase 10 第 01 到 05 课，或具备 tokenization、数据管道、预训练与扩展方面的同等知识。

**第一课：** [提示工程](01-prompt-engineering/)

在仓库根目录运行这条命令：

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

记住命令本身、退出码、生成的 prompt 元数据、测试结果，以及你改动的那一处 prompt 带来的输出差异。该演示使用模拟的模型响应，不需要 API key。

**下一步：** 说明你改的是哪个 prompt 变量、它为什么改变了行为，然后继续学习[少样本、思维链与思维树](02-few-shot-cot/)。

浏览[完整的 Phase 11 课程列表](../../README.md#phase-11)或[跨阶段路线图](../../ROADMAP.md)。
